Free code signing provided by [SignPath.io](links:signpath), certificate by [SignPath Foundation](links:signpathFoundation).

## What's signed

`Unishade.exe`, `UnishadeUi.dll` and Unishade Setup, as published on [GitHub Releases](links:releases). GitHub Actions builds them from [Unishade's repository](links:github), and each release is signed only after an approver approves it.

ReShade, the effects and the add-ons that Setup downloads come from their own authors, and Unishade doesn't sign them. The macOS and Linux builds aren't signed.
